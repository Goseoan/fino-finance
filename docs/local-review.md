# 공개 소스 검수 기록

검수일: 2026-11-21. 실제 계정·금융 자료를 사용하지 않고 별도 소스 사본과 합성 데이터만 검증했습니다.

## 검증

- 단위/정합성 테스트 46개 통과.
- 타입 검사 및 최종 프로덕션 빌드 통과.
- 추가 분류 기능 전 전체 브라우저 검사 39개 통과.
- 분류·그룹 추가 후 집중 회귀 8개 통과: 카드/그리드 일치, 사용자 분류/미분류 보존, 중복/누락, 검색, 소계, 용도 수동 지정, 금액 저장과 모바일 화면.
- 자산 그룹과 지출 그룹의 합성 자료 화면 검토.
- macOS 셸 실행 스크립트 구문 및 AppleScript 컴파일 확인.

## 공개 제외와 코드 정리

개인 기록·재무 합계·문서 ID·OAuth 클라이언트/토큰·개인 경로·개발 이력을 제외했습니다. 예제 설정은 빈 값으로 제공합니다. 사용자별 고정 문서 ID는 설정으로 대체하고 개인 설치 경로를 고정하지 않습니다. 테스트는 합성 자료이며 원본 로컬 저장소와 별도입니다. 운영 자료·백업·캡처·캐시·의존성은 공개 트리에 포함하지 않습니다.

공개 후보와 Git 스테이징/커밋 트리에서 개인 식별 문자열, 비밀키/토큰 패턴, 실제 Google 문서 링크, 개인 경로, 예기치 않은 바이너리/데이터 파일을 검사합니다. 새 저장소의 초기 커밋으로 구성하며 원본 작업 이력을 옮기지 않습니다.

## 남은 범위

- 정적 패턴 검사는 향후 추가되는 파일의 모든 개인정보를 자동 보증하지 않습니다. 추가 커밋마다 공개 범위를 다시 확인해야 합니다.
- 실제 Google 계정에 대한 OAuth·읽기·쓰기는 이번 합성 검증에 포함하지 않았습니다. 테스트는 SDK 모양의 대체 구현을 사용합니다.
- 신규 시트의 임의 형식 자동 매핑, 다중 사용자 인증, 은행 자동 조회는 제공하지 않습니다.
- 로컬 OAuth 파일은 소유자 파일 권한으로 보호하며 별도 암호화 저장소는 아닙니다. Google OAuth 범위는 앱 탭 하나만 허용하는 권한이 아니며 앱이 쓰기 범위를 제한합니다.
- 애매한 자동 분류는 검토 필요 또는 미분류로 표시합니다. 실제 기록을 추측 변경하지 않았고, 자산 유형의 표시 정규화는 원본 문자열을 바꾸지 않습니다.
