# 분류·그룹 표시 기준

## 원본 기록 보존

이 기능은 저장된 자산 유형이나 지출 현금흐름 구분을 일괄 변경하지 않습니다. 자산명으로 자산 유형을 추측하지 않습니다. 기존 사용자 분류는 유지하며 수정할 때만 사용자가 선택한 값을 저장합니다. 자동 마이그레이션이 없어 데이터 변경 미리보기나 되돌리기 작업이 필요하지 않습니다. 그리드 편집은 저장 전 취소할 수 있고 변경 전 백업을 생성합니다.

## 자산

기본 유형 표시 순서는 현금 → 투자 → 연금 → 부동산 → 기타 → 미분류이며 사용자 유형은 그 뒤 가나다순입니다. 공백·한글 조합 방식의 차이는 표시할 때만 정리합니다. 빈 표시값은 미분류로 남깁니다. 원래 저장 문자열은 바꾸지 않습니다.

카드와 그리드는 같은 검색·유형 필터와 그룹 기준을 사용합니다. 그룹은 표시 중인 미삭제 자산을 한 번씩 포함합니다. 항목 수에는 비활성 자산도 포함하며 **활성 평가액 소계**는 활성 자산만 합산합니다. 각 그룹 안은 한글·숫자 자연 정렬을 적용한 이름순, 동일 이름은 ID로 순서를 안정화합니다. 그리드의 평가액 정렬은 그룹 안에서만 바뀝니다.

그리드 그룹과 소계는 저장된 상태 기준입니다. 유형이나 금액을 편집 중인 행은 저장 전 다른 그룹으로 이동시키지 않아 입력 위치를 유지합니다. 저장하면 새 그룹과 합계에 반영됩니다. 숨겨진 선택 행은 현재 필터의 선택 삭제 대상에 포함하지 않습니다.

## 고정지출

현금흐름 구분과 세부 용도는 독립적입니다. 예를 들어 투자 관련 급여공제는 용도가 투자일 수 있어도 현금흐름상 급여공제라는 값은 그대로 유지합니다. 표시 명칭은 `소비 지출`, `생활비 예산`, `급여 공제`, `대출 상환`처럼 띄어쓰기를 정리하지만 저장 키는 바꾸지 않습니다.

- 수동 지정 용도를 항상 우선합니다. 기존 사용자 지정 용도도 그룹과 필터에 포함합니다.
- 이름에 명확한 근거가 있을 때만 자동 용도를 제안합니다. 가족 지원처럼 여러 용도가 가능한 분류는 수동 선택으로 바꿀 수 있습니다.
- 일반 쇼핑 서비스명이나 용도를 알 수 없는 저축/투자 자동이체는 특정 상품으로 추측하지 않고 **검토 필요**로 표시합니다.
- 이름과 분류에서 용도를 결정할 근거가 없으면 **미분류**로 남깁니다. 직접 지정한 기타는 유지합니다.
- `ISA` 같은 약어가 다른 영단어의 일부인 경우 투자로 오인하지 않고, 전기차 비용을 전기요금으로 분류하지 않도록 구체적 패턴을 사용합니다.

용도는 기본 목록 순서, 사용자 용도는 가나다순입니다. 기본 항목 순서는 이름순이며 표의 정렬 버튼은 그룹 내부 순서를 바꿉니다. 그룹 소계는 현재 검색/필터에서 보이는 활성 항목의 월 환산 **배정액**입니다. 저축·급여공제가 포함될 수 있으므로 순수 소비 합계와 혼동하지 마세요.

사용자 분류 이름이 `전체`여도 전체 보기와 충돌하지 않습니다. 자산 필터에는 `전체 (사용자 유형)`으로 표시하고, 고정지출의 모든 용도 선택은 사용자 용도 값과 구분합니다. 정렬 상태는 시각 표시와 접근성 속성으로 함께 알립니다.

현금은 입출금·CMA/파킹·정기예금·적금·청약·보유 현금 등 세부 유형으로 그룹/필터를 제공합니다. 이름 기반 제안은 자동 표시이며, 사용자가 직접 지정한 `cashType`을 우선합니다. 출자금/연금/투자처럼 현금으로 단정하기 어려운 이름은 유형 검토 필요로 표시합니다. 원래 자산 유형을 자동 이동시키지 않습니다.

## 현금흐름과 사용처

현금흐름 구분은 소비지출·생활비예산·저축/투자·급여공제·대출상환의 경제적 성격을 나타내고, 세부 용도는 보험·통신·주거·구독 같은 사용처를 나타냅니다. 보험·세금·구독을 단지 서로 다른 용도라는 이유로 저축이나 급여공제로 바꾸지 않습니다. 현금흐름 표시는 세부 용도를 함께 보여 주며, 고정지출 수정 화면에서 선택한 분류의 포함/제외 기준을 설명합니다.

일괄 분류 점검·정정·되돌리기 패널은 제거했습니다. 기존에 정리한 분류와 항목별 수정 이력은 유지하며, 이후 분류 변경은 각 항목의 수정 화면에서 진행합니다.
