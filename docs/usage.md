# 사용 방법

이 안내의 예시는 모두 가상 데이터 기준입니다. 앱은 개인용 로컬 서버이며 은행 거래를 실행하지 않습니다.

## 처음 실행

1. Node.js 20.9 이상을 설치하고 프로젝트 폴더에서 `npm ci`를 실행합니다.
2. `npm run dev`로 시작하고 `http://127.0.0.1:3000`을 엽니다.
3. 데이터가 없는 새 설치는 `/connect`를 직접 엽니다. Google 연결 없이 살펴보려면 서버를 종료한 뒤 `FINANCE_E2E=1 npm run dev`로 가상 데이터 모드를 시작합니다(macOS/Linux).
4. 서버를 끄려면 실행한 터미널에서 Control+C를 누릅니다. 같은 포트에 두 서버를 동시에 띄우지 마세요.

테스트 모드는 별도 데이터와 OAuth 파일을 사용합니다. 실제 계정의 인증정보를 입력하는 용도로 사용하지 마세요. 일반 모드로 돌아가려면 테스트 서버를 종료하고 `npm run dev`로 시작합니다.

자산 유형별 그룹, 소계와 지출 용도의 검토 기준은 [분류 안내](classification.md)를 참고하세요.

## 자산 등록과 수정

- **자산 관리 → 자산 추가**에서 이름·유형·기관·평가액·평가일을 입력합니다. 투자원금은 선택 사항입니다.
- 카드의 수정 버튼으로 한 항목을 변경하거나 **그리드 보기**에서 여러 행을 편집한 뒤 **일괄 저장**합니다.
- 금액에는 천 단위 쉼표가 자동 표시됩니다. `1,000,000`을 붙여넣을 수도 있으며 저장 시 숫자로 처리합니다.
- 그리드의 평가액을 바꾸고 날짜를 따로 바꾸지 않으면 오늘 날짜로 기록됩니다. 과거 기록을 수정할 때는 평가일을 확인하세요.
- 그리드에서 행을 선택해 삭제할 수 있습니다. 삭제한 항목은 설정의 휴지통에서 확인합니다.

## 현금 세부 유형

자산 수정의 **현금 세부 유형** 또는 그리드에서 직접 지정합니다. 미지정이면 이름 기반 제안을 표시합니다. 현금은 세부 유형별 소계로 나뉘며 **현금 세부 유형 필터**로 원하는 항목만 볼 수 있습니다. 상품 성격이 불명확한 항목은 검토 표시를 확인하고 유형/세부 유형을 직접 수정하세요.

## 잔액 수정 전후 이력

자산의 변경 추이 아래 **잔액 수정 전후 이력**을 펼치면 수정 시각·평가일·이전 잔액·수정 후 잔액을 볼 수 있습니다. 변경이 두 건 이상이면 수정 시각 기준 차트도 표시합니다. 같은 평가일을 여러 번 고쳐도 각 금액 변경을 보존합니다.

날짜별 차트는 해당 날짜의 최종 잔액이며, 수정 전후 이력은 이 기능 적용 이후의 기록입니다. 이전 버전에 남아 있지 않은 과거 수정 전후 값은 생성하지 않습니다. 이름/분류 변경은 금액 변경이 아니므로 금액 차트에 새로운 잔액을 만들지 않습니다. 날짜별 과거 기록과 가져온 기록은 기존 추이에서 별도로 확인합니다. 이 이력은 앱의 수정 기록이며 은행 거래 원장이 아닙니다.

수정 이력을 삭제하면 해당 이력 차트에서도 사라집니다. 날짜별 잔액 기록의 삭제와 수정 이력 삭제는 별도입니다. 자산 영구삭제는 연결된 수정 전후 이력도 정리합니다. 별도 자동 백업 파일의 보존 범위는 백업 안내를 참고하세요.

## 날짜별 기록과 추이

**오늘의 자산 등록**에서 확인한 잔액만 수정하고 변경사항을 검토한 뒤 저장합니다. 바꾸지 않은 자산은 이전 평가일을 유지합니다. 항목별 변경 추이와 이력 화면에서 기간별 값을 확인할 수 있습니다. 누락된 값을 0원으로 대체하지 않으며 총자산 기록을 개별 자산에 임의 배분하지 않습니다. 현재 자산 분류로 묶은 추이는 과거의 분류와 다를 수 있습니다.

## 과거 자산 상세 기록 가져오기

Google 연결 후 **이력 및 통계 → 과거 자산 상세 기록 가져오기 → 과거 기록 미리보기**를 누릅니다. 미리보기에서 추가할 상세 값 수·기존 값 유지·지원하지 않는 탭·대응 불명확 항목을 확인하고 **과거 기록 반영**을 누릅니다.

날짜 이름의 탭에서 `대구분 / 중구분 / 소구분 / 현저축액` 표를 읽습니다. 이름이 정확히 대응되고 숫자 잔액이 확인되는 값만 가져옵니다. 겹치는 기존 기록은 유지하며 원금·기관 등으로 추측해 합치지 않습니다. 이름 변경 전의 관리 탭 별칭도 참고합니다. 오래된 미지원 형식과 대응되지 않는 자산은 검토가 필요합니다.

가져온 값은 현재 잔액·평가일·분류나 순자산 총액 기록을 바꾸지 않는 별도 상세 이력입니다. 자산/유형 추이에 **시트 가져옴 · 미확인**으로 표시합니다. 원본 기준일을 알 수 있고 탭 날짜와 다르면 함께 표시합니다. 누락은 0원이 아니며 원본 합계를 항목별로 배분하지 않습니다. 개별 상세 기록은 가져온 기록 목록에서 삭제하고 휴지통에서 복원할 수 있습니다. 휴지통에 있는 날짜를 자동 재생성하지 않습니다.

## 고정지출

- **고정지출 → 지출 추가**에서 항목, 현금흐름 구분, 금액, 납부주기, 납부일과 계좌를 등록합니다.
- **현금흐름 구분**은 소비지출·생활비예산·저축/투자·급여공제·대출상환의 계산상 의미를 결정합니다.
- **세부 용도**는 보험·통신·가족 지원·구독 등 목록을 묶는 표시용 분류입니다. 기본값은 이름 기반 자동 분류이며 수정 화면에서 직접 지정할 수 있습니다.
- 검색과 두 필터를 함께 사용할 수 있습니다. 그룹 합계는 현재 필터에 표시되는 활성 항목의 **월 환산** 합계입니다. 급여공제·저축 등을 포함하는 배정액이며 순수 소비 총액과 같지 않습니다.
- 회당 납부액과 월 환산 예산을 구분하세요. 연간 납부액의 월 환산은 실제 월 출금액과 다릅니다. 납부일 표시는 출금 완료를 의미하지 않습니다.

## 대출과 수입 설정

**대출 관리**에서 잔여 원금·금리·상환 방식·기간을 입력합니다. 계약과 잔액을 확인한 경우 확인 상태를 체크합니다. 금리 시뮬레이션은 참고 계산이며 금융기관 견적이나 실제 상환 거래가 아닙니다.

**설정**에서 계획 월수입과 간이 DSR용 연소득을 변경합니다. 연소득을 0으로 두면 해당 비율을 계산하지 않습니다. 계산은 입력한 가정에 따라 달라집니다.

## 삭제·백업·복원

- 항목 삭제는 휴지통으로 이동합니다. 설정에서 복원 또는 영구삭제를 선택합니다.
- 날짜 기록 삭제는 해당 날짜 스냅샷과 연결된 총액 기록을 함께 제거합니다.
- 전체 삭제는 설정값과 데이터를 비우고 복원용 상태를 휴지통에 보관합니다. 전체 복원은 새 데이터가 없는 상태에서 허용합니다.
- JSON 내보내기로 별도 백업을 저장할 수 있습니다. 이 파일에는 개인정보와 금융 데이터가 들어 있으므로 공개 저장소에 넣지 마세요.
- 변경 전 자동 백업은 `.data/backups/`에 남습니다. 앱 휴지통의 영구삭제가 이 별도 백업 파일까지 삭제하는 것은 아닙니다.

## Google 연결

README의 Google 설정을 먼저 완료합니다. OAuth 승인 후에는 저장 범위를 확인하고 **실제 저장소 연결**을 눌러야 활성화됩니다. 연결 실패 시 기존 로컬 데이터를 데모로 바꾸지 않습니다. 연결을 해제하면 마지막으로 읽어 검증한 로컬 사본을 이용합니다.

Google 권한은 `spreadsheets` 읽기·쓰기 범위입니다. 권한 자체는 앱 탭 하나에 한정된 Google 권한이 아니며, 앱 코드가 지정한 문서의 앱 탭과 소유자 메타데이터로 쓰기를 제한합니다. 개인용 복사본을 선택하고 동의 화면의 권한을 직접 확인하세요.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 3000 포트 사용 중 | 기존 서버를 사용하거나 종료 후 다시 실행 |
| OAuth 설정 필요 | 저장한 콜백 주소와 브라우저 주소의 호스트·포트 일치 여부 확인. `localhost`와 `127.0.0.1`은 별개 호스트 |
| Google 403 / 테스트 사용자 차단 | Google Cloud Audience의 테스트 사용자 등록 |
| Sheets API 비활성 오류 | OAuth 프로젝트에서 Sheets API 활성화 후 잠시 기다렸다 재시도 |
| 승인됐는데 미연결 | 저장 범위 확인 후 실제 저장소 연결 버튼 클릭 |
| 최초 가져오기 실패 | 지정된 관리 탭/열 구성과 자산·이력 합계 확인. 빈 문서는 초기 데이터가 되지 않음 |
| 쓰기 소유권 충돌 | 처음 연결한 설치에서 실행. 소유권을 임의로 탈취하거나 설치 ID를 복사하지 않음 |
| 잠금 파일 충돌 | 관련 앱 서버가 모두 종료된 것을 확인한 뒤 잔존 `.data/google-writer-*.lock` 파일만 제거 |

Google 테스트 상태 앱의 승인/리프레시 토큰은 만료될 수 있습니다. 만료되면 다시 로그인하세요. 인증정보는 채팅·이슈·스크린샷으로 공유하지 마세요.
