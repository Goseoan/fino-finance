# 초기 가져오기용 관리 탭 형식

이 문서는 구조만 설명하며 실제 문서 ID나 금융 기록을 포함하지 않습니다. 첫 행은 제목 행으로 취급하고 두 번째 행부터 가져옵니다. 형식이 다른 시트는 복사본에서 맞추거나 `lib/migration.ts`의 매핑을 수정해야 합니다. 이 작업 자체가 Google 문서를 생성하거나 수정하지는 않습니다.

## 02_자산현황

| 열 | 값 |
| --- | --- |
| A | 고유 자산 ID |
| B | 자산 분류. `동산`은 앱에서 `기타`로 매핑 |
| C | 기관/계좌 종류 |
| D | 자산명. 괄호 안 기관명이 있으면 표시 기관으로 사용 |
| E | 원 단위 평가액, 숫자 |
| F | 투자원금, 숫자 또는 빈 셀 |

평가일은 최신 이력의 원본 기준일을 사용합니다. 이름에 개인 식별정보를 넣으면 앱 백업과 저장소에도 함께 보관됩니다.

## 03_대출관리

| 열 | 값 |
| --- | --- |
| A | 고유 대출 ID |
| B | 대출명 |
| C | 잔여 원금 |
| D | 소수 비율 금리. 예를 들어 `0.04`는 4% |
| E | 약정 월 원금. 양수이면 원금균등, 0이면 만기일시로 가져오기 |

기간·만기·금리 변경일·계약 확인 여부는 앱에서 별도로 확인해 수정합니다.

## 01_월고정지출

| 열 | 값 |
| --- | --- |
| A | 고유 지출 ID |
| C | 항목명 |
| D | `소비지출`, `생활비예산`, `저축·투자`, `급여공제`, `대출상환` 중 하나 |
| E | `월`, `분기`, `6개월`, `연` 중 하나 |
| F | 회당 납부액 |
| H | 납부일 1~31 또는 빈 셀 |
| I | 계좌 표시명 |
| J | 활성 상태. `중지`와 `보류`는 비활성 처리 |

세부 용도는 앱이 이름으로 제안하며 항목 수정에서 직접 선택할 수 있습니다.

## 05_이력분석

| 열 | 값 |
| --- | --- |
| A | 원본 기록 식별값 |
| B | 기록 날짜 `YYYY-MM-DD` |
| C | 원본 기준일 `YYYY-MM-DD` |
| H | 당시 총자산, 숫자 |
| I | 당시 총부채, 숫자 |
| L | 선택적 메모 |

최신 이력의 총자산·부채는 가져오는 자산/대출 합계와 같아야 합니다. 총액 이력만 있는 과거 시점은 개별 자산의 상세 잔액으로 추정하지 않습니다.

## 06_설정·가이드

| 셀 | 값 |
| --- | --- |
| B5 | 계획 월수입 |
| B6 | 기타 월수입 |
| B7 | 간이 DSR용 연소득 |

금액은 숫자 셀로 저장하세요. 앱은 최신 값만 읽으며 해당 관리 탭의 수식이나 셀을 자동 수정하지 않습니다.

## 이미 앱 전용 저장소가 있는 경우

유효한 `08_앱데이터` 문서가 있으면 이를 우선 사용합니다. 앱 전용 문서의 서명·체크섬·revision·쓰기 소유권을 직접 편집하지 마세요. 새 앱 저장소에 로컬 작업본을 올리는 옵션은 실제 로컬 작업본이 있을 때만 허용되며 기존 앱 기록을 임의로 덮어쓰지 않습니다.
