# 급여명세서 관리

메뉴의 **급여명세서**에서 사진의 실제 지급·공제 항목을 데이터로 관리하고 시점별로 비교합니다. 원본 사진은 근거 자료로 연결합니다. 앱의 급여 기록은 기존 SQLite DB의 별도 급여 테이블에 저장합니다. 원본 시트·금융기관·계획 소득·자산 잔액을 자동으로 바꾸지 않습니다.

## 등록과 확인

1. **명세서 등록**에서 사진을 선택합니다. JPG·PNG·WebP를 각 10MB 이하, 한 번에 합계 30MB 이하, 명세서당 6개까지 지원합니다.
2. 귀속월, 지급일, 급여/상여/연말정산/기타 구분과 이름을 입력합니다. 사진만 보관하고 나중에 입력해도 됩니다.
3. 지급·공제 세부 항목과 총액을 입력합니다. 빈 값은 미확인으로 유지하고 환급·정산은 음수도 지원합니다.
4. **세부 항목 합계로 총액 채우기**를 누르면 모두 입력된 세부 항목을 합산합니다. 빈 목록을 0원으로 가정하지 않습니다.
5. 원본과 금액을 대조한 뒤 **원본과 금액 확인 완료**를 선택하고 저장합니다. 귀속월과 세부 항목/총액, `지급액 − 공제액 = 실수령액`을 검증합니다.

월별 추이는 확인 완료한 명세서만 집계합니다. 같은 달 급여와 상여는 합산하며, 기록이 없는 달을 0원으로 채우지 않습니다. 연말정산의 실제 환급·추징을 기록할 때는 해당 정산 금액을 입력하고, 연간 소득 전체를 월급에 중복 등록하지 마세요.

## 기기 내 사진 읽기

**사진에서 값 읽기 · 로컬**은 macOS의 Vision과 Swift 명령행 도구를 사용합니다. 사진을 외부 OCR 서비스에 전송하지 않습니다. macOS와 Xcode Command Line Tools가 필요하며, 그 밖의 환경에서는 직접 입력으로 모든 관리 기능을 사용할 수 있습니다. 자동 읽기는 첫 사진의 문서 종류·날짜·지급/공제 세부 항목·총계를 분석하고 항상 검토 대기로 돌립니다. 월급여 명세표의 지급/공제 열을 구분해 읽으며, OCR의 오독이나 누락은 원본과 합계로 검토해야 합니다. 읽지 못한 값·복수 후보는 비워 둡니다. 임시 이미지와 OCR 원문은 읽기 후 지웁니다.

서버 실행 위치에 `scripts/payroll-ocr.swift`가 있어야 합니다. 최초 Swift 실행이나 큰 사진은 시간이 걸릴 수 있으며 최대 2분으로 제한합니다. 문서 종류·글꼴·기울기·흐림에 따라 읽기 정확도가 달라지므로 확인 완료 전에 원본을 직접 확인하세요.

## 수정·삭제·백업

수정 전후 기록을 원본 사진 참조와 함께 보관합니다. 삭제는 급여 화면의 휴지통에서 복원할 수 있습니다. 영구 삭제는 연결된 급여 기록·전용 수정 이력·다른 기록에서 참조하지 않는 사진을 제거하며, 직전 로컬 백업을 만듭니다.

**사진 포함 급여 백업**은 모든 급여 기록·휴지통·수정 이력·사진을 JSON으로 내려받습니다. **급여 백업 복원**은 범위를 확인한 후 현재 급여 자료만 교체하고 교체 전 백업을 생성합니다. 사진 해시·참조·형식·버전을 검증합니다. 다운로드는 95MB, 업로드는 100MB까지 지원합니다. 이보다 큰 자료는 서버 종료 후 DB와 WAL/SHM을 함께 백업하세요.

**급여 엑셀 내보내기**는 명세서·지급/공제 항목·수정 이력의 조회용 보고서입니다. 원본 사진은 엑셀에 넣지 않으므로 전체 복원에는 사진 포함 급여 백업을 사용하세요.

자산·지출·대출의 JSON 백업/복원·전체 비우기·Google 전송은 급여 자료와 별도입니다. 급여 기록을 삭제하려면 급여 화면의 휴지통을 사용하세요. 급여 사진을 Google에 자동 전송하는 기능은 제공하지 않습니다. DB·급여 백업·원본 사진·OCR 임시 파일은 공개 소스에서 제외합니다.

## 분석된 내역과 비교

기본 화면은 사진 갤러리 대신 지급액·공제액·실수령액과 분석된 항목 수를 보여 줍니다. **지급·공제 항목별 비교** 표에서는 등록된 시점별 본봉·수당·상여·후생비·세금·보험료 등을 비교합니다. 사진에 없는 항목은 미기재로 표시하고 0원으로 바꾸지 않습니다. 증감은 이전 등록 시점 대비이며, 연속된 월의 변화라고 가정하지 않습니다. 원본 사진은 상세 화면의 접힌 근거 자료에서 확인합니다.

**연간소득**과 **퇴직금**은 기준 연도/일자와 별도의 참고 항목으로 관리합니다. 연간 근로소득 총액, 과거 3개월 급여총액, 퇴직금 예상액을 월급으로 넣지 않습니다. 이 자료는 확인 완료 상태여도 월별 급여·실수령액 합계와 비교 표에서 제외합니다. 퇴직금 예상 조회는 실제 지급액이나 확정 자산이 아닙니다. 참고 항목은 값과 단위를 구분해 소수인 지급률도 원 금액으로 반올림하지 않습니다.
